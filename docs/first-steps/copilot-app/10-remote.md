This lesson is optional, and worth saving until the local loop feels natural. The `/remote` command continues the session you are already in on GitHub, so you can step away from your machine and keep following it.

In this lesson, you will:

- continue an in-progress session remotely.
- follow the remote session from your browser.
- review the resulting changes like any other pull request.

## Continue a session remotely

1. Open a session that has work in progress.
2. Run `/remote` to continue that session remotely.
3. Select the link it returns to open the remote session in your browser.
4. Follow its progress from there, then review the changes exactly as you would any other pull request.

> [!NOTE]
> **This is not delegation**
>
> You are not handing the task to a different agent. It is the same session, continuing somewhere you can reach from any device.
